# QR Code Generator

A simple web-based QR Code Generator that converts a website URL into a QR code. Users can enter a URL, generate its QR code, preview it, and download it as a PNG image.

## Features

* Enter any website URL
* Generate a QR code instantly
* Preview the generated QR code
* Download the QR code as a PNG image
* Simple and responsive user interface
* Runs completely in the browser

## Technologies Used

* HTML5
* CSS3
* JavaScript
* QRCode.js
* GitHub Pages

## Project Structure

```text
QR/
├── index.html
├── style.css
├── script.js
└── README.md
```

## How It Works

1. User enters a website URL.
2. JavaScript validates the URL.
3. QRCode.js generates the QR code.
4. The QR code is displayed on the webpage.
5. User can download the QR code as a PNG image.
